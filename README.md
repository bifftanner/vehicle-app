# Vehicle Application
My project is a vehicle app where I have created 3 vehicles and test abstract classes and interfaces
## Features
1. Prints all vehicles automatically
2. Prints all vehicles that implement StreetLegal automatically
3. Creates a save file using CSV to save created vehicles
4. Has readfile feature to read CSV and recreate saved vehicles

There is no menu inside of this app, it just prints the vehicles required and quits.
